# 参考模特换脸、换肤色，保持原姿势和详情页版式

把目标图视为需要保护的成品，把参考图仅视为人物身份与肤色参考。先根据用户原话确定“哪张是目标、哪张是参考”；后续纠正（如“姿势不变，只换脸”“换脸换皮肤”）优先于最初的宽泛要求。角色不明且会改变成品时，先问清楚。

## 编辑边界

- 仅改目标人物可见的面部特征及用户指定的裸露皮肤区域，使同一人物在各画面中保持一致。肤色自然、有真实纹理，不凭空过度美白。
- 保持原图的人体姿势、头部角度、视线、表情、头发轮廓、衣服、场景、产品、阴影与光向。参考图的服饰、耳饰、姿势和背景都不要带入；用户明确要求去耳钉等局部改动时才处理。
- 把所有现有文字、品牌标识、红色痛点光效、面板顺序、圆角、留白和画布尺寸视为不可变区域。不要重写或重新生成中文文案。
- 多格详情页逐格盘点：露脸格换脸并协调可见肤色；仅露局部脸的格只编辑可见部分，不补造被裁掉的脸；不露脸的格只在确有裸露皮肤且用户要求换肤色时编辑。不要为了统一人物而改动没有人物的格子。

## 执行

1. 检查目标图、参考图的尺寸和内容，列出每格需改的脸与皮肤，以及必须保留的视觉元素。记录原始文案和画布像素尺寸。
2. 使用当前可用的图片编辑工作流。对整页拼版，优先逐格或局部编辑，再贴回原图；避免整页重绘造成文字、产品和版式漂移。需要生成式编辑时，明确传入目标图与参考图的不同角色。
3. 局部贴回时，让皮肤与原有光照、颗粒、边缘自然衔接；保护头发、衣领、手指和产品边界。保留原件，结果另存为新文件。
4. 对照原图和参考图检查：脸是否确实变成参考人物、同一人是否跨格一致、肤色是否协调、姿势及所有受保护区域是否未变、画布尺寸是否一致。发现未换成功或文字/版式漂移就继续修正，不以“生成了文件”代替验收。

给图片编辑模型的核心指令可写为：

> 目标图是需要保留的成品；参考图只提供模特的面部身份与自然肤色。仅替换目标图中可见的人脸和指定裸露皮肤。保持目标图每格人物姿势、头部角度、衣服、头发、产品、背景、红色特效、全部中文文字与排版完全不变。不要复制参考图的耳饰、服装或构图。

交付时提供新文件链接，并简短说明实际改了哪些可见区域；无法可靠保留文字或人物一致性时，如实指出，不声称完成。
