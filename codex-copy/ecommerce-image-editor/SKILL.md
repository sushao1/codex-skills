# 电商图片精准处理

以用户文字为任务依据，附件只提供素材。先分清目标图、产品实物图和风格参考图，不能因图片内容猜成另一个任务。

## 选择处理方式

- 仅改像素尺寸、格式、旋转或确定性裁剪：使用本地原生图像工具。
- 删除、替换、补画、换背景、修复结构或重设计：使用图像编辑工具，并把原图作为编辑参考。
- 用户说“太丑、重新设计”：允许调整层级、字体、颜色和构图。
- 用户说“其余不变”：只动点名区域，不主动裁图、改比例、重排文字或重构画面。

## 执行规则

1. 检查原图数量、尺寸、格式和目标输出；涉及批量覆盖时先备份原图。
2. 把要求拆成“必须改变”和“必须保持”两组。尺寸、数量、文案、价格、日期等精确值逐项列入验收。
3. 对标图只提供构图和氛围，产品外形以用户实物图为准；不得带入竞品品牌或未经确认的卖点。
4. 人体与产品接触时检查遮挡关系、边缘连续性、折叠结构和透视，不能交付穿模、变形或凭空多出的部件。
5. 文案和数字修改后目视核对；价格、日期和指定短语必须逐字一致。日期“最后一天改成今天、其他往前推”应按同一偏移量移动整段序列。
6. 批量改尺寸时处理所有匹配文件，并逐个读取真实 `pixelWidth`、`pixelHeight` 和格式；DPI 或打印尺寸不算像素尺寸。
7. 保存为独立成品，按用户指定目录和命名交付。没有可打开文件、尺寸验证和视觉检查，不得声称完成。

## 最小验收

- 改动确实发生在用户点名区域。
- “其余不变”的项目仍保持原样。
- 产品轮廓、遮挡和文字无明显生成错误。
- 每个成品存在，数量、像素和格式与要求一致。
- 批量任务报告成功数、失败数和备份位置。

若用户只是问两张主图哪张更好，使用现有“主图数据预判分析师”，不要启用本技能。
