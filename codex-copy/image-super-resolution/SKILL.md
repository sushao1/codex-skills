# 图片超分修复

把“超分修复”理解为保真放大：提升可用分辨率，尽量恢复边缘清晰度，但不凭空改写原图内容。

## 工作规则

- 先清点输入：文件数量、自然排序、格式、宽高和是否为同一张长图的分屏。保留原文件，所有输出放到新的版本目录。
- 连续详情页必须先按原顺序无损拼合，再对整页超分，最后按原边界的同倍率坐标切回，避免屏与屏之间的文字、人物和产品细节不一致。
- 默认使用可复现的超分模型（项目已有 SRMD ncnn Vulkan 时优先），2倍、`noise-level=0`、`tile=256`；不得用生成式重绘、换脸、美颜、色彩校正、额外锐化或新增材质纹理代替超分。
- 如果模型或命令不可用，不要把普通插值放大冒充超分。可以输出诊断结果并说明阻塞原因，除非用户明确接受插值备选。
- 不能把“清晰”写成“真实恢复了原始细节”。模糊或压缩丢失的信息只能改善观感，不能证明被准确找回。

## 验收

完成后必须读回并记录：

1. 输出数量、文件格式、每张最终宽高；目标2倍尺寸要逐张核对，不能只凭文件名或命令成功判断。
2. 连续图的拼合前后边界、标题、人物、产品孔洞、细小正文和透明/白底区域是否出现裁切、错位、重复或新增内容。
3. 将输出缩回原尺寸做整体一致性核对（可记录 RMSE 等指标）；这只能作为一致性证据，不能代替逐图视觉检查。
4. PNG 等无损格式优先；如用户要求 JPG，明确压缩是交付格式变化而非超分质量证明。

## 交付

在输出目录写一份简短处理记录，至少包含输入范围、模型/倍率/去噪参数、是否先合并后切分、输出尺寸和未验证限制。交付时同时给出原图未覆盖的输出目录和关键尺寸核验结果。

对于商品图，严格区分“产品身份”和“参考风格”：超分过程中保留原产品外形、颜色、结构、文字和顺序；不得借机套用参考图里的产品、参数或卖点。
