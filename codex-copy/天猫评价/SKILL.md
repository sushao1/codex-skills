# 电商真人感评价写作 Skill

## 1. 核心目标

输出必须像“真实买家自己写的”，不是广告文案，不是客服话术，不是 AI 模板。

优先级从高到低：
1. 真实感
2. 逻辑通顺
3. 口语化
4. 卖点清晰
5. 场景合理
6. 不重复、不模板化
7. 不过度推销

如果“卖点”和“真人感”冲突，优先真人感。

## 2. 适用任务

当用户提出以下需求时启用本 Skill：
- 写一条/多条买家评价
- 重写评价
- 优化评价
- 写追评
- 初评接追评
- “换五种思维方式写”
- “换五种不同表达”
- “口语化一点”
- “故事性一点”
- “焦虑+解决”
- “根据图片写评价”
- “根据卖点写评价”
- “这个需求点怎么打”
- “问大家怎么写”
- 电商产品真实使用感受文案

## 3. 总体语言规则

### 3.1 必须做到

- 用大白话。
- 句子要顺，前后有因果。
- 像消费者随手打字，而不是精修广告。
- 一条评价只打 1 个主卖点，最多顺带 1 个辅助点。
- 评价中优先出现“我、家里、最近、用了几天、平时、晚上、中午”等真实口语连接词。
- 用户给了原句时，尽量保留原来的意思，只换表达和逻辑。
- 用户说“简单一点”，就控制在 20–35 字左右。
- 用户说“故事性”，要有“为什么用 → 怎么用 → 用完感受”。
- 用户说“不要故事性”，直接写体验，不强塞场景。
- 用户说“换角度”，必须换思路，不是只换几个同义词。

### 3.2 禁止写法

不要出现以下明显模板感/广告感句式：
- “本来以为……没想到……”
- “终于……”
- “神器”
- “闭眼入”
- “强烈推荐”
- “效果绝了”
- “YYDS”
- “谁买谁知道”反复滥用
- “比预想中稳”
- “质量非常好/效果非常好”这种空泛硬夸
- 每条都用同样的“用了几天/用了半个月/最近一直”开头

除非用户明确要求夸张营销风，否则默认不用营销口号。

### 3.3 写实规则（重要，所有评价必须遵守）

所有感受描述必须写实，禁止只写抽象感受词。

- **禁止只写**：“踏实”“舒服”“放松”“暖和了”“舒服多了”“挺好的”“效果不错”这类空泛感受词。
- **必须写出具体因为什么**：
  - 具体身体部位（腰、脚、肩、眼、肚子）
  - 具体场景/动作（上床不用灌热水袋、脚捂一会儿就暖、腰那块不冰、早上起来肩膀不僵）
  - 对比过去的做法（以前躺半天脚还是冰的 → 现在很快暖；以前要端着水倒 → 现在开排水口就行）
- **感受词可以留，但必须紧跟一个具体事实支撑**。
- 例：
  - 错：钻进被窝也踏实。
  - 对：上床不用再灌热水袋，脚捂一会儿就暖，腰那块也不冰了。
  - 错：戴着挺舒服。
  - 对：戴着睡一晚脖子不硌，早上起来肩膀不僵。
  - 错：用着很放松。
  - 对：洗完澡躺上去按十分钟，腰那块就不发硬了。

### 3.4 写作优先级（百无禁忌）

- **先把评价写好、写真实、写有记忆点，再考虑合规。**
- **真实感、具体、有冲击力 > 过度保守的措辞。**
- 用户明确要求的功效点（如祛湿、痘痘、黑眼圈、睡眠、消水肿等），按用户给的方向写实写，不要每次都自作主张软化或加合规提醒。
- 合规风险由用户自己把控，写作环节不要过度自我审查，不要因为顾虑太多把评价写烂。

### 3.5 写前先搞清楚产品怎么用（强制）

- **写任何一条评价前，必须先搞清楚这个产品具体怎么使用、什么形态、什么部位用、什么场景用。**
- 不要只凭产品名就开写：
  - 艾灸罐是戴身上绑带固定的，不是放桌上烧的；
  - 脚动滚轮款不能写自动按摩；
  - 折叠款要写清楚收在哪、怎么用。
- **如果用户没说清用法、图片也看不出来，先问一句“这个是怎么用的/戴哪/放哪”，不要凭印象瞎写。**
- 用法写错会让整条评价假得离谱（比如把随身灸写成“放桌上烧”），这是最伤真实感的错误。

## 4. “五种思维方式”到底怎么写

用户说“换五种思维方式”，不是改五遍同一句。

必须从不同认知角度切：
1. 使用前顾虑 → 使用后验证
2. 生活场景 → 产品解决问题
3. 长期使用 → 稳定性/耐用
4. 对比自己过去的习惯 → 现在更方便
5. 意外发现的小细节 → 形成真实体验

例如“秤很准”，不能五条都写“连续称三次一样”。
可拆成：
- 和体检秤对比
- 和健身房秤对比
- 砝码测试
- 已知重量物品测试
- 连续称重稳定
- 家人轮流称
- 长期使用数据稳定

每条角度必须有真实差异。

## 5. 评价结构模板

### 5.1 普通真人评价
结构：场景/原因 + 使用动作 + 感受

例：
> 中午办公室灯一直开着，戴上以后眼前暗很多，趴着睡不会一直觉得晃眼。

### 5.2 焦虑 → 解决
结构：原来担心什么 + 实际使用结果

注意：不要机械使用“本来担心”。

例：
> 家里地方不大，还怕泡脚桶不用的时候没地方放，好在能直接折起来塞柜子下面。

### 5.3 故事性
结构：为什么买/当时发生什么 → 用了 → 结果

例：
> 今天赶早班高铁，起得太早，上车就想补会儿觉。还好昨晚把眼罩放包里了，戴上以后外面的光基本看不到。

### 5.4 简短型
20–35 字，一句话讲清楚。

例：
> 用了快一个月，平时一直在称，到现在数字还是挺稳。

## 6. 初评与追评规则

### 6.1 追评不能重复初评
初评已经讲“充电方便”，追评就不要再讲 Type-C。
初评已经讲“桶深”，追评优先讲排水、恒温、折叠、清洗等。

### 6.2 最自然的追评逻辑
初评：刚收到时能看到的东西
→ 包装、颜值、做工、功能入口

追评：用一段时间后才能知道的东西
→ 精准度、续航、耐用、恒温、清洗、稳定性、长期感受

### 6.3 追评衔接方式
可用：
- “用了几天才发现……”
- “前面只注意到……后来发现……”
- “用久了最喜欢的反而是……”
- “最近一直在用，顺便补充一下……”
- “这个点用一阵子以后感受更明显……”

避免每条都写“用了有一阵子”。

## 7. 图片评价规则

看到图片后，优先从图片里真实可见的细节写：
- 人物姿势
- 使用环境
- 摆放位置
- 产品大小
- 收纳方式
- 光线
- 房间/宿舍/办公室/高铁等场景
- 产品与周围物体的比例
- 使用动作

禁止编造图片里看不到、用户也没说过的功能。

例如：图片里泡脚桶折叠后塞在沙发和边几缝隙：
> 我家地方不大，用完折起来直接塞沙发旁边，平时不碍事。

不要凭空写“自动杀菌”“遥控”“静音电机”等。

## 8. 冰丝眼罩写作规范

### 8.1 常用需求点
- 遮光性
- 鼻梁贴合、不漏光
- 不压眼睛
- 侧睡不硌
- 松紧可调
- 不闷热
- 冰凉感
- 透气
- 水洗不掉色
- 可清洗
- 没有异味
- 轻、无束缚感
- 耐用

### 8.2 推荐场景
- 办公室午休
- 学校宿舍午休
- 高铁
- 飞机
- 酒店
- 早晨房间进光
- 对象玩手机/开灯
- 靠窗位置

### 8.3 禁区
不要写：
- 戴着出汗
- 粘毛
- 闷出汗
- 去黑眼圈

可写：
- “光线影响小了”
- “午休更安静”
- “更容易静下来”
- “睡着后基本没什么存在感”
- “贴脸凉凉的”
- “睡一晚也不闷”

### 8.4 真人词汇优先
优先：
- 凉凉的
- 滑滑的
- 软软的
- 不勒
- 不硌
- 不顶
- 挺轻
- 没啥存在感
- 眼前暗很多

少用：
- 亲肤
- 柔润
- 0压感
- 云感
- 极致透气
- 丝滑触感

除非用户明确要营销表达。

## 9. 体重秤 / 体脂秤写作规范

### 9.1 常用需求点
- 精准度
- 称重稳定
- 灵敏度
- APP 自动记录
- 数据全面
- 斤/公斤切换
- Type-C 充电
- 续航
- 玻璃厚
- 用料扎实
- 站上去不响
- 颜值
- 赠品实用
- 老人操作方便

### 9.2 精准度必须有“证据”
不要只写：
> 这个秤很准。

更真实：
- 连续称 2–3 次数字一致
- 和体检中心一样
- 和健身房一样
- 10kg 砝码测出来 10kg
- 已知重量物品对比

注意：
“250ml 牛奶 = 0.25kg”并不天然严格成立，因为包装重量和液体密度会影响。
如果用户坚持该表达，可按用户事实改写，但 Skill 默认不主动制造这种“精确证明”。

### 9.3 APP 评价
常用自然逻辑：
> 以前称完转头就忘，现在数据自己同步到 APP，哪天轻了哪天重了都能看到。

避免把 APP 写成说明书。

### 9.4 续航
真实表达：
> 买回来快一个月了，上次充电还是刚收到的时候，现在电量还挺足。

不要随意承诺固定续航天数。

## 10. 折叠泡脚桶写作规范

### 10.1 常用需求点
- 质量好
- 折叠功能
- 不漏电 / 水电分离
- 桶深 / 桶高
- 买给家人 / 送礼
- 噪音小
- 容易清洗
- 恒温
- 加热快
- 排水方便
- 温度范围
- 温度加减
- 脚动按摩
- 冷水加热
- 药包
- 操作简单
- 桶大小
- 不漏水
- 折叠耐用

### 10.2 折叠评价
要写“具体收哪”：
- 柜子下面
- 洗衣机旁
- 沙发边
- 墙角
- 床边柜下面
- 卫生间缝隙

例：
> 家里卫生间不大，泡完晾干直接折起来塞洗衣机旁边，不怎么占地方。

### 10.3 桶深/桶高
真实点：
> 水能泡到小腿下面。

不要夸成“泡到膝盖”除非产品尺寸确实支持。

### 10.4 排水
最自然逻辑：桶深、水多 → 不想端 → 排水口省力

例：
> 水加得多还好不用自己端着倒，泡完开排水口就行。

### 10.5 恒温
可和过去普通盆对比：
> 以前泡一会儿水就凉了，现在调好温度后能一直保持着，不用中途兑热水。

### 10.6 加热快
真实小故事：
> 水加好开着加热，我去洗个脸回来温度就已经上来了。

不要凭空写具体几分钟，除非用户提供。

### 10.7 按摩功能
如果产品是脚动滚轮款，绝对不能写自动按摩。

正确：
> 泡的时候脚底自己来回踩滚轮，轻重自己控制。

错误：
> 开机自动按摩脚底。

### 10.8 安全
可写：
- 水电分离
- 使用期间没有异常
- 出水口不渗水
- 排水塞密封正常

不要无依据保证：
- “100%不会漏电”
- “绝对安全”
- “国家级防漏电”

## 11. 睡眠护腰带写作规范

常用卖点：
- 承托腰部
- 躺睡支撑
- 不硌
- 透气
- 夏天不闷
- 轻薄
- 可调节
- 久睡/久坐场景

自然写法：
> 家里床比较硬，昨晚戴着睡了一晚，腰下面有个支撑，躺着舒服不少。

透气：
> 夏天戴着也没觉得热，透气性还可以，睡一晚上不会闷。


## 12. 艾灸罐写作规范

### 12.1 常用需求点
- 艾草味
- 烟味不大
- 不呛
- 做工
- 耐用
- 安全
- 不烫
- 调理/放松
- 使用方便
- 绑带固定

### 12.2 安全/温度
真实表达：
> 刚开始还怕会太烫，实际用的时候就是温温热热的，没有烫疼的感觉。


## 13. 美塑仪写作规范

常见需求点：
- 瘦身效果
- 按摩
- 充电续航
- 产品质量
- 热敷
- 噪音
- 砭石
- 用户提到的肠胃/便秘场景

### 13.1 瘦身效果写法
优先写视觉/穿衣感受：
- 腰线明显一点
- 裤腰松一点
- 腰腹看着紧实一点
- 手臂线条看着利落些

## 15. 常见用户指令的处理方式

### “口语化一点”
把书面词换成日常词。

例：
“佩戴体验较为舒适”
→ “戴着挺舒服的”

“无明显束缚感”
→ “不会勒得慌”

### “故事性一点”
加入真实起因和动作，不要堆卖点。

### “简单一点”
删掉原因，只留体验。

### “换五种不同思维”
五条必须是五种场景/证据/关注点。

### “不要太刻意”
去掉“特意测试、专门看、为了验证”等措辞。

### “不要推销感”
删掉：
- 推荐
- 必入
- 真香
- 太值了
- 神器
- 性价比绝了

### “第一人称”
必须出现“我/我家/我妈/我老公/我们”。

## 16. 输出格式规则

用户要“一条”：直接给成品，不解释。

用户要“五条”：只给 5 条，不多给。

用户要“追评怎么写”：先判断初评打的卖点，再给最适合的追评；如果需要，可补 3–5 个备选方向。

用户要“需求点怎么打”：先标注需求点，再给一句自然问法/评价。

用户要求表格：严格按表格返回。

## 17. 最终自检清单

每次输出前检查：
- [ ] 像真人说话吗？
- [ ] 有没有广告腔？
- [ ] 逻辑前后通顺吗？
- [ ] 有没有重复用户刚写过的卖点？
- [ ] 如果是五条，角度真的不同吗？
- [ ] 有没有“本来以为…没想到…”这种用户不喜欢的模板？
- [ ] 有没有“终于”“神器”“强烈推荐”等过度推销词？
- [ ] 用户说简短时是否足够短？
- [ ] 用户说故事性时是否真的有起因、过程、结果？
- [ ] 所有感受词都有具体事实支撑吗（有没有只写“踏实/舒服/放松”而没写因为什么）？
- [ ] 有没有因为过度顾虑合规而把卖点软化成温吞水、导致评价平淡没记忆点？
- [ ] 写之前搞清楚产品具体怎么用了吗（戴身上/放桌上、自动/手动、什么部位）？用法没搞清楚先问，不要凭印象瞎写。

## 18. 默认生成风格

如果用户没额外要求，默认：
- 中文
- 第一人称
- 30–60 字
- 一条只打一个核心卖点
- 自然口语
- 有一点生活场景，但不过度编故事
- 不夸张
- 不像广告
- 不虚构事实
