# 四区面板织物质感迁移

## 目标

以图1作为**材质参考图**，以图2作为**唯一编辑目标**。只把图2四块面板的表面质感改成图1的效果：

- 柔软织物包覆
- 细密、真实且不过度锐化的布纹
- 厚实软垫和轻微回弹感
- 自然压线、包边与阴影层次
- 柔和哑光表面，避免金属感和硬塑料感

图1只提供材质、纹理、软硬感与光影参考，不能复制图1的产品造型或配色。

## 必须锁定的内容

除四块面板的材质及其必要光影外，图2以下内容全部保持不变：

- 产品结构、轮廓、面板形状、比例和视角
- 产品位置、尺寸、朝向及四块面板之间的间距
- 原有灰色配色；不得改成图1的其他颜色
- 支架、调节结构、边框及其他零部件
- 背景、构图、排版、装饰、图标、品牌与全部文字
- 画布比例与主图用途

若图1上下两组面板纹理不同，可对应迁移：上方使用细纹织物和弧形压线，下方使用柔软织物绗缝纹理；不得改变图2原有压纹走向或面板轮廓来强行套用。

## 执行流程

1. 明确图片角色：用户发送顺序默认为图1是参考图、图2是编辑目标；用户另有说明时以其说明为准。
2. 先检查图2的结构、配色、文字和版式，列为不可变项。
3. 使用内置图像编辑工具，将两张图片一起传入：图1标注为 material reference only，图2标注为 edit target。
4. 提示词中重复强调“只换材质，不换造型；只编辑图2”。
5. 生成后检查：四块面板是否都有织物感，产品是否仍是图2，灰色是否保留，文字与版式是否完整。
6. 若有结构漂移、文字变化、产品移位或图1造型被复制，继续做一次定向修正，不把错误版本当成成品。
7. 非破坏性保存为新文件，不覆盖原图；向用户提供可点击的绝对路径。

## 编辑提示词骨架

```text
Use case: precise-object-edit
Asset type: 电商商品主图
Primary request: 编辑图2。仅将图2产品四块面板的材质质感改成图1产品的效果：柔软织物包覆、细密真实布纹、厚实软垫感、柔和哑光表面、自然压线和边缘包边，并匹配图1的细腻立体光影。去除图2面板过度光滑、坚硬、像金属或塑料的质感。
Input images: Image 1 is the material and texture reference only; Image 2 is the edit target.
Materials/textures: 保留图2原有面板轮廓与压纹布局，只将表面呈现改为柔软织物和软垫效果。边框保持图2原有灰色结构，表面低调半哑光，不要镜面金属感。
Constraints: 只改变图2四块面板的材质、纹理及相应真实光影；保持图2产品结构、形状、比例、视角、位置、尺寸、支架、灰色配色、背景、排版、图标、品牌和全部文字不变。
Avoid: 不要复制图1的产品造型或颜色；不要移动、缩放或重构图2产品；不要修改文字；不要改变版式；不要新增、删除部件、文案、标志、水印或场景。
```

将图2实际可见文字逐项加入 `Constraints`，要求逐字保留。不要凭空补写看不清的文字。

## 后续微调

用户说“再白一点”时，只把织物软垫和外框整体提亮一档，保持浅灰白层次、布纹和阴影，避免纯白过曝或与白色背景融为一体。其他内容仍然不动。

用户说“质感再明显一点”时，优先加强织物微纹理、软垫厚度、边缘包边和柔和侧光；不要通过改变产品形状或大幅加深颜色制造立体感。

## 完成标准

- 四块面板全部呈现柔软织物软垫，而不是金属或硬塑料
- 布纹细密自然，保留灰色并有清晰层次
- 图2原有结构、位置、比例、背景和版式未改变
- 所有可见文字完整、清晰、无乱码
- 输出为新文件并完成尺寸检查
